# Kuch-Bhi

A personal playground repository where I explore and build hands-on projects for random backend and system engineering topics.

---

## Projects

### 1. [redis-and-db](./redis-and-db)
A hands-on lab exploring PostgreSQL storage and Redis in-memory caching strategies. It implements a complete CRUD REST API using Docker containers for PostgreSQL and Redis, high-resolution latency tracking for reads and writes, and compares the 4 core Redis caching patterns (Cache-Aside, Write-Through, Write-Behind, and Write-Around) with an interactive visual dashboard.

### 2. [ai-agent](./ai-agent)
An autonomous research, computation, and intelligence agent powered by Next.js 16, React 19, and the Vercel AI SDK. Features multi-step chain-of-thought reasoning, parallel multi-tool dispatch, and 6 specialized operational tools (live web search, sandboxed JavaScript code execution, scientific calculator, weather intel, crypto market metrics, and inter-step scratchpad memory) with an interactive UI and autonomous error recovery.
